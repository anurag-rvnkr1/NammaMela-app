# 🎭 NammaMela – AI Based Drama Recommendation App

NammaMela is an Android-based entertainment application designed to help users discover and explore dramas through an intelligent and user-friendly platform. The app provides AI-based recommendations, secure authentication, smooth navigation, and a modern UI experience for users who enjoy discovering trending and personalized entertainment content.

---

## 🚀 Features

- 🔐 User Authentication (Login & Registration)
- 👤 Forgot Password Functionality
- 🤖 AI-Based Drama Recommendations
- 🎬 Trending & Popular Drama Listings
- ❤️ Personalized User Experience
- 🔎 Search and Explore Functionality
- 📱 Modern Android UI/UX Design
- ☁ Firebase Integration
- ⚡ Fast and Responsive Navigation
- 🔔 Loading States and User Feedback

---

- **Android Studio**

## 📌 Problem Statement

Finding entertainment content that matches user interests can be difficult due to the huge number of available options and lack of personalized recommendations. Many users spend a lot of time searching for suitable dramas and shows.

NammaMela solves this problem by providing:
- AI-powered recommendations
- Personalized suggestions
- Organized browsing experience
- Fast and easy content discovery

## ⚙ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/anurag-rvnkr1/NammaMela-app.git
```

### 2️⃣ Open Project

- Open Android Studio
- Click on **Open Existing Project**
- Select the cloned project folder

### 3️⃣ Configure Firebase

- Create a Firebase project
- Add `google-services.json`
- Enable:
  - Firebase Authentication
  - Firebase Realtime Database / Firestore

### 4️⃣ Run the Application

- Connect Android Device or Emulator
- Click ▶ Run
